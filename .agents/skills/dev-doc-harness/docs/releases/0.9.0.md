# Dev Doc Harness 0.9.0

## Release

Dev Doc Harness `0.9.0` consolidates the durable planning, execution, model-selection, and changelog-lifecycle contract into a clearer, more directly executable distribution package.

## Package Contents

The distributable package is root `AGENTS.md` plus `.agents/`.

It does not include this repository's `docs/work-items/`, root `README.md`, root `CHANGELOG.md`, `.git/`, or local development files.

## Added

- Added explicit `TASK` and `CHECK` planning entities, task-bound evidence, and consistent conformance recording.
- Added portable orchestration-mode and model-facet notation, including clear continuity, review, authorization, context, and integration boundaries.

## Changed

- Made `SKILL.md` the sole operational router; refined lifecycle, freeze, execution-start, and variance boundaries without changing the release package boundary.
- Simplified and regenerated small/medium and phased planning templates, including commitment/criterion form, task/check coverage, documentation assessment, and release-context prompts.
- Clarified changelog-fragment authoring and consolidation so root history is complete before release-note curation while frozen historical compatibility remains intact.
- Preserved Superpowers compatibility as an optional workflow aid while the harness remains the canonical owner of durable artifacts, approvals, and implementation records.

## Compatibility

Harness release versions carry compatibility meaning.

Stable `module:*`, `rule:*`, and `schema:*` IDs remain unversioned anchors. Compatible clarifications update current policy and release notes; incompatible replacements retain a discoverable replacement note.

## Team Adoption

Copy root `AGENTS.md` and `.agents/` into the target repository, merge local `AGENTS.md` instructions carefully, run validation when practical, and commit the harness update separately from product work.

## Rollback

Revert the dedicated harness update commit or PR to restore the previous root `AGENTS.md` and `.agents/` package.
