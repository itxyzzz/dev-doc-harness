# Dev Doc Harness 0.10.0

## Release

Dev Doc Harness `0.10.0` streamlines its planning routes and adds a compact lean/small flow for bounded work while preserving the established package boundary and release contract.

## Package Contents

The distributable package is root `AGENTS.md` plus `.agents/`.

It does not include this repository's `docs/work-items/`, root `README.md`, root `CHANGELOG.md`, `.git/`, or local development files.

## Added

- Added the lean/small planning flow, its compact templates, approval-equivalent freeze controls, operator guidance, and validation coverage.

## Changed

- Renamed active planning routes and their template, schema, assembly, and validator namespaces to `small` and `medium`, while retaining the established large/phased route and immutable historical records.
- Refined lean/small execution startup, work-size guidance, templates, and structural checks following review feedback.

## Compatibility

Harness release versions carry compatibility meaning.

Stable `module:*`, `rule:*`, and `schema:*` IDs remain unversioned anchors. Compatible clarifications update current policy and release notes; incompatible replacements retain a discoverable replacement note.

## Team Adoption

Copy root `AGENTS.md` and `.agents/` into the target repository, merge local `AGENTS.md` instructions carefully, run validation when practical, and commit the harness update separately from product work.

## Rollback

Revert the dedicated harness update commit or PR to restore the previous root `AGENTS.md` and `.agents/` package.
