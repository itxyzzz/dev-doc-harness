# Dev Doc Harness 0.4+

## Release

Dev Doc Harness `0.4+` adds source-block assembly for the primary planning templates while keeping the published templates self-contained.

## Package Contents

The distributable package is root `AGENTS.md` plus `.agents/`.

It does not copy this repository's root `README.md`, root `CHANGELOG.md`, root `TODO.md`, `docs/work-items/`, `.git/`, `.githooks/`, or other local development files.

## Added

- Added ordered template source blocks under `assets/templates/blocks/`.
- Added explicit assembly manifests under `assets/templates/assemblies/`.
- Added `scripts/assemble_templates.py` with `--list`, `--check`, and `--write`.
- Added validation coverage for generated-template freshness and block or manifest structure.

## Changed

- Changed the small/medium and large/phased spec and plan templates to be generated flat Markdown files.
- Changed current requirement, acceptance-criterion, and risk examples to use `###` headings with tag IDs.
- Changed the package-local release marker from `0.3.0` to `0.4+`.

## Compatibility

Agents and downstream adopters still consume complete Markdown templates from `assets/templates/`.

Maintainers edit source blocks and manifests, then run the assembler before committing template changes.

## Team Adoption

Copy root `AGENTS.md` and `.agents/` into the target repository, merge local `AGENTS.md` instructions carefully, run validation when practical, and commit the harness update separately from product work.

The optional `.githooks/` files in this repository are not part of the distributable package.

## Rollback

Revert the dedicated harness update commit or PR to restore the previous root `AGENTS.md` and `.agents/` package.
