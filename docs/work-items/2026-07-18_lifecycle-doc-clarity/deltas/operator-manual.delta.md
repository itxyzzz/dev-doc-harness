## Proposed Update

User-facing lifecycle guidance will show that a frozen combined package needs a
fresh start authorization before implementation. Large/phased work freezes the
anchor, requires a fresh instruction before phase-plan drafting, freezes each
approved phase plan, and requires fresh authorization before phase
implementation. Each approval decision visibly returns to its draft when the
operator supplies feedback.

The concise planning explanation will say that plans define the intended result
and boundaries, tasks perform the work, and checks supply verification evidence.
Stable IDs and explicit mappings remain proportional planning aids rather than
an operator workflow to learn.

An approved execution selection is recorded in the applicable planning artifact
before freeze. A large/phased anchor spec may record it; it is not metadata
created only after a fresh authorization.
